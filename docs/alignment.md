# GTO 德州扑克训练应用：需求对齐结论

对齐日期：2026-10-13

## 产品定位
- 主要给自己用，不做账号、付费和多平台分发。
- 界面只做中文，扑克术语保留常用英文缩写（3bet、EV、VPIP 等）。

## 游戏规则
- 现金局，2 到 6 人桌由玩家自由选择。
- 固定 100bb，无抽水。
- 第一版所有对手都打 GTO，不做风格化对手。

## GTO 策略来源
- 翻前：查表。2 到 6 人、每个位置的范围表由我们自己离线求解。
  - 简化下注树：开池 2.5bb，3bet 和 4bet 各一两种尺寸，再加全下。
  - 支持导入自定义范围，可以覆盖默认值。
- 翻后，两人底池：实时求解，基于开源的 postflop-solver（Rust，AGPL），把代码复制进仓库后由我们自己维护。
  - 使用精确模式（更多下注尺寸、更深迭代），每条街等待 10 到 60 秒。
  - 一发牌就开始在后台求解，同时显示进度条。
- 翻后，多人底池：用规则近似。纠错照常给出，但标注“近似”。

## 训练功能
- 第一版：边打边纠错（GTO 动作频率和你损失的 EV，可以开关），以及打完复盘（手牌历史、逐街回放、标出 EV 损失最大的决策）。
- 第二版：专项练习、长期数据统计。

## 技术方案
- 桌面应用：Tauri + React 界面 + Rust 求解器。
- 目标机器：Windows，i9-13900H（14 核 20 线程），32GB 内存，RTX 4060 笔记本显卡（8GB 显存）。
- 应用内实时求解：只用 CPU 多线程。
- 翻前离线求解工具：只用 CPU 多线程（2026-10-13 根据实测改定，不再做 GPU 版）。实测 6 人在 4 线程上每轮约 2.8 秒，所以不需要 GPU。
- 范围表在用户的笔记本上跑（需要装 Rust），可以通过远程 Claude Code 会话执行。

## 验收标准
- 用可剥削度衡量：翻后精确模式低于底池的 0.3%，翻前低于 1bb/100 手。
- 用库恩扑克和 Leduc 做算法的单元测试。

## 开发顺序
1. 求解器优先：先做翻前（CPU 多线程）和翻后求解，并通过验收标准。
2. 再做规则引擎、牌桌界面、即时纠错、复盘。
